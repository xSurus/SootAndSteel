# B2.1 menus port plan

Branch `port/ui-menus` (from main b37dc91). `Src/` is read-only. Follow `Unity/CONVENTIONS.md` and the handoff testing rules (C# 9, netstandard2.1, never `-quit` with `-runTests`, one Unity process at a time, `git add Unity/Assets`, commit per task).
Slice: main menu, pause overlay, options menu, controls overlay in UI Toolkit. Out of scope: hub, shop, HUD, tooltips, post-level screens, join screen.

## Decisions

- View models live in Gamelab.Core under `Gamelab.UI.ViewModels`, System.Numerics only. `ISoundService` lives in Runtime (it needs FMOD types), so `OptionsViewModel` takes a small Core interface `IVolumeSettings` (settings getter plus three setters). A Runtime adapter wraps `ISoundService`.
- Navigation logic is engine-free. `IInputActions` is already in Core, so `MenuNavigator` (Core, namespace `Gamelab.UI`) takes `Func<IReadOnlyList<IInputActions>>` and an `Action playSelect`, and is tested with fake inputs. Runtime supplies the list from `PlayerJoinManager.Roster.Slots` and the sound from `ISoundService`. Src semantics kept: Up/Down move and play MenuSelect, Pickup confirms, Pause toggles pause, Left/Right adjust sliders (no sound).
- Main menu: per-player selection (`MainMenuViewModel` as in Src `Src/UI/ViewModels`), any player can navigate and confirm. Entries built by the owner: Continue (only with a save), New Game, Options, Quit. Rows selected by anyone are marked as selected, with small P1..P4 tags like `MainMenuPanel`.
- Pause flow mirrors `PauseMenuController` plus `GameplayScreen.UpdatePauseMenu`: each frame, if any player pressed Pause and options is not open, toggle (this also closes controls and options); then if paused, options open goes to the options handler, controls open closes on any Pickup or Pause (with sound), else root navigation (up/down over Continue, Options, Controls, Exit, wrap, sound; Pickup confirms with sound). Toggle resets selection to 0. Exit raises an event.
- Pause uses `Time.timeScale = 0`. `PlayerInputHandler`'s directional repeater ticks with `Time.deltaTime`, which is 0 while paused, so hold-to-repeat would die. Switch it to `Time.unscaledDeltaTime` (menu only reads the repeater).
- Views: `Assets/Resources/UI/<Name>.uxml` and `.uss`, loaded with `Resources.Load` (tests need them without a scene, same as B1 map art). Shared style in `UI/Common.uss`. One MonoBehaviour per screen (`MainMenuView`, `OptionsMenuView`, `PauseMenuView`, `ControlsOverlayView`) binding a `UIDocument` to its view model, and two controllers (`MainMenuController`, `PauseMenuController`) that own the models, views and navigator and tick in `Update`. Screen-space only.
- `PanelSettings` is created in code by `UiPanel` (scale with screen size 1920x1080, shrink match, matching Gum's uniform scale `min(w/1920, h/1080)`), shared by all documents of a controller.
- Layout units come from the Gum project files (`Src/Content/GumProject`), design canvas 1920x1080. Gum unit codes: dimension 0 absolute, 1 percent of parent, 3 percent of source file, 4 relative to children; position 0 from left, 1 from top, 2 percent width, 3 percent height, 4 from right, 6 from center X, 7 from center Y.
- Art: copy Title.png, spr_pause_paper_burnt_380x280.png, spr_controls.png, spr_chevron_32.png, FMOD Logo png to `Assets/Resources/UI/Art/`. `UiSpriteImportSettings` postprocessor (Point, no compression, no mipmaps, sprite, PPU = pixel width, max 8192). Fonts: Src uses pre-rendered BMFont caches from system fonts (Ubuntu Mono, Special Elite, Bodoni MT), so no TTF is in the repo. Download OFL/UFL/Apache TTFs for Ubuntu Mono and Special Elite; Bodoni MT is commercial, use Libre Bodoni (OFL) or record it as not ported. Put them in `Assets/Resources/UI/Fonts/` with their licence files. If a download fails, fall back to the Unity default font and record it.
- Options row layout deviation: Gum places the options row container at 21.35% of the paper width, which puts a 340 px wide row about 89 px off the paper. Centre it (50%) instead and record this.
- Controls overlay: the controller image has the labels baked in. Only the Close button glyph (Xbox A from `XboxButtonAtlas`) becomes a text label "A". Record the glyph deferral in CONVENTIONS.
- Rotation: Gum rotation is counter-clockwise, UI Toolkit `rotate` is clockwise, so the 1 degree paper tilt becomes `-1deg`. Unverified visually.
- Main menu input gap: nothing creates a player before the join screen, so a main menu scene needs some `IInputActions` in the roster. The navigator takes any list; record the gap.

## Tasks (TDD, tests, commit, then task review)

1. Core view models and navigator. `Core/UI/ViewModels/`: `MainMenuViewModel` (port), `OptionsViewModel` (port, `IVolumeSettings`, `VolumeStep` default 0.05), `PauseMenuModel` (items Continue/Options/Controls/Exit, `IsPaused`, `ControlsOpen`, selection wrap, `Toggle`, `Confirm`, `ExitRequested`), `Core/UI/MenuNavigator.cs`. EditMode tests under `Tests/EditMode/UI/`: selection wrap, per-player selection, confirm invokes entry, volume step and clamp through a fake `IVolumeSettings`, pause toggle rules (options open blocks toggle, toggle closes subpanels, selection reset), navigator sequences with fake inputs (sound counts, options closes on pickup or pause, controls closes on pickup or pause, left/right no sound).
2. UI plumbing and assets. Art and fonts imported, `UiSpriteImportSettings` (Editor) plus EditMode importer test, `Common.uss`, Runtime `UiPanel` (PanelSettings factory), `UiResources` loader helper, `SoundVolumeSettings : IVolumeSettings` adapter over `ISoundService`. Tests: importer settings, resources load, PanelSettings values, adapter with a stub.
3. Main menu and options screens. `MainMenu.uxml/.uss`, `OptionsMenu.uxml/.uss`, `MainMenuView`, `OptionsMenuView`, `MainMenuController`. PlayMode tests: rows built from entries, Continue absent without save, selection class follows the view model, P-tags, layout numbers from `resolvedStyle`, options open/close visibility, slider thumb position and percent text follow volume, controller drives the models from fake inputs and plays sound through a stub.
4. Pause and controls. `PauseMenu.uxml/.uss`, `ControlsOverlay.uxml/.uss`, `PauseMenuView`, `ControlsOverlayView`, `PauseMenuController` (timeScale 0 while paused, restored on unpause and on destroy), `PlayerInputHandler` unscaled delta. PlayMode tests: overlay visibility per model state, only one panel visible at a time, timeScale set and restored, controller full flow with fake inputs (pause, navigate, open controls, close, exit event), repeater advances while timeScale is 0.
5. CONVENTIONS section, then the lead runs both full suites.

Final: whole-branch review (most capable model), one fix wave, one scoped re-review. Verify EditMode and PlayMode, `git diff b37dc91 -- Src/` empty, `dotnet build Src/Gamelab.csproj`, no stray `.meta`.
